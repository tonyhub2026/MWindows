# MWindows

> 下載:請到右側 **Releases**,下載最新版的 `.zip`。需要啟用碼才能使用。

## 開啟

1. 把下載的 `.zip` **按右鍵 →「全部解壓縮」**,再執行解壓出來的資料夾裡的 **`MWindows.exe`**。
   不要在壓縮檔裡面直接點兩下。
2. 出現「**Windows 已保護您的電腦**」:按「**其他資訊**」→「**仍要執行**」。
3. 出現「**是否允許此 App 變更您的裝置?**」:建議按「**是**」(遊戲以系統管理員執行時才控制得到滑鼠)。
4. 出現缺少 `vcomp140.dll` / `MSVCP140.dll`:先安裝微軟
   [Visual C++ 可轉散發套件(x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

## 啟用

在「啟用碼」欄位輸入 16 碼啟用碼,按「啟用」,顯示綠色「已授權」即可。之後開啟會自動記住。

> 換電腦時直接在新電腦輸入同一組啟用碼,舊電腦會同時失效。

## 使用

1. 讓遊戲畫面完整顯示在螢幕上(不要被其他視窗擋住)。
2. 按「**開始**」,必要時程式會自動接手滑鼠。
3. 按「**停止**」或鍵盤 **Esc** 停止,滑鼠立刻還給你。

燈號:🔴 紅 = 已停止 / 🟢 綠 = 執行中 / 🟡 黃 = 進行中

## 常見問題

- **無法連線到授權伺服器**:確認網路正常,稍後再按一次「啟用」。
- **此啟用碼已在另一台電腦啟用**:正在別台電腦使用,或本月換電腦次數已用完。
- **授權已到期**:請聯絡賣家續約。
