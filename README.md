## 開啟

1. 把下載的 `.zip` **按右鍵 →「全部解壓縮」**,再執行解壓出來的資料夾裡的 **`MWindows.exe`**。
   不要在壓縮檔裡面直接點兩下。
2. 出現「**Windows 已保護您的電腦**」:按「**其他資訊**」→「**仍要執行**」。
3. 出現「**是否允許此 App 變更您的裝置?**」:建議按「**是**」(遊戲以系統管理員執行時才控制得到滑鼠)。
4. 出現缺少 `vcomp140.dll` / `MSVCP140.dll`:先安裝微軟
   [Visual C++ 可轉散發套件(x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

## 啟用

在「啟用碼」欄位輸入 16 碼啟用碼,按「啟用」,顯示綠色「已授權」即可。之後開啟會自動記住。

**活動期間加入 LINE 官方好友 https://lin.ee/NeJcPBY 領取免費序號。**

> ⚠ **每組啟用碼限一台電腦使用;換電腦登入每月限 2 次。**
> 換電腦時直接在新電腦輸入同一組啟用碼,舊電腦會同時失效。

## 快速開始

程式有兩個功能,都要先完成上面的「啟用」才能用:

- **追蹤** — 按上方的「**開始**」,程式會自動偵測畫面、接手追蹤。按「**停止**」或**按住**鍵盤 **Esc** 約半秒結束,滑鼠立刻還給你。
- **自動巡邏** — 先照下面的「**設定教學**」把路線設定好,再按下方的「**啟動 (F10)**」。巡邏進行中若需要追蹤,會自動暫停巡邏、切去追蹤,結束後再接著巡邏。

燈號:🔴 紅 = 已停止 / 🟢 綠 = 執行中 / 🟡 黃 = 進行中

## 設定教學(自動巡邏)

> 第一次設定前:**把遊戲解析度設成 1366**,並讓遊戲畫面完整顯示在螢幕上(不要被其他視窗擋住)。

### 1. 定位遊戲視窗
按「**遊戲視窗定位**」,程式會把遊戲視窗移到固定位置。**每次要設定路線前都先按一次**,之後再開始記錄定點和繩子。

### 2. 選地圖
在「**地圖**」下拉選單選一張地圖;每張地圖是一組獨立的路線設定。
- 「**改名**」「**刪除**」:管理地圖。
- 下拉選單最上面的「**＋**」:新增一張空白地圖。

### 3. 設技能鍵
點「**技能**」旁的方塊(顯示「(點一下再按鍵盤)」),再按一下你遊戲裡的攻擊/技能按鍵即可。
> 設定按鍵時請切換成**英文輸入法**,中文輸入法會讓程式讀不到按鍵。

### 4. 設延遲
「**延遲**」這一列:
- **定點**:勾起來後,角色每到一個定點會放幾次技能、每次之間間隔幾秒(秒數 / 次數)。不勾就只走點、不放技能。
- **移動中**:勾起來後,移動途中每隔幾秒也放一次技能。

### 5. 記錄定點(路線上的點)
定點就是「角色要依序走到的點」。
1. 按「**＋ 新增定點(右鍵刪除)**」新增一個欄位。
2. 讓角色站到要記錄的位置,按「**記錄定點**」,就會記下目前站的座標。
3. 重複以上,把路線上每個要停的點都記起來。多記的欄位按**右鍵**可刪除。

### 6. 設順序
在「**順序**」欄位填定點編號(例如 `1 2 3`),決定巡邏時依什麼順序走,走完回到第一個形成循環。欄位按**右鍵**可刪除。

### 7. 記錄繩子
如果路線中需要爬繩子往上,要先把**整段移動會用到的每一條繩子**都記起來:
1. 按「**＋ 新增繩子(右鍵刪除)**」。
2. 讓角色站到**繩子正下方的地面**,按「**記錄繩子**」。
3. 每一條會用到的繩子都記一次。

### 8. 存檔
設定好後按「**存檔**」,把這張地圖的設定存起來(按鈕上有 `*` 代表有改動還沒存)。下次開啟會自動載入。

### 9. 開始 / 停止巡邏
- 按「**啟動 (F10)**」或鍵盤 **F10** 開始自動巡邏(同時也會開啟追蹤)。
- 按「**停止 (F12)**」或鍵盤 **F12** 停止巡邏。

### 多台電腦共用設定(選用)
設定好的地圖可以搬到別台電腦用:
- 「**匯出**」:把目前這張或全部地圖存成一個檔案。
- 「**匯入**」:在另一台電腦把檔案載進來(名稱重複時可選擇改名、覆蓋或略過)。

## 常見問題

- **無法連線到授權伺服器**:確認網路正常,稍後再按一次「啟用」。
- **此啟用碼已在另一台電腦啟用**:正在別台電腦使用,或本月換電腦次數已用完。
- **授權已到期**:請聯絡賣家續約。
- **按了按鍵卻沒反應/設技能讀不到**:請把輸入法切成**英文**再試一次。
- **滑鼠控制不到遊戲**:遊戲若以系統管理員執行,請讓 MWindows 也以系統管理員執行(開啟時那題按「是」)。

## 資料與隱私

程式會連線驗證啟用碼,並將遊戲部分畫面資料加密回傳以改善辨識;
每局結束時也會回傳一份執行摘要(畫面更新速度、遊戲區大小與位置、顯示縮放、是否以系統管理員執行、游標軌跡)以協助排除問題;
不會收集遊戲畫面以外的螢幕內容、檔案或個人資料。
